# showcase — 基盤の使い方を示す画面

`packages/` にある **114 の基盤パッケージ**を、動く画面とソースで確認できます。

「README を読んでも使い方が分からない」を減らすためのものです。
実際に触って、隣にあるソースを見れば、自分のアプリへ持っていけます。

## 起動

```bash
pnpm dev:showcase   # http://localhost:3001
```

**DB は要りません。** データはすべてメモリかモックなので、そのまま起動できます。

## 中身

**87 画面**あります。全体像はトップページか、サイドバー(`src/lib/nav.ts` が正)から辿ってください。

| 区分 | 例 |
|---|---|
| 基盤の部品 | 表・フォーム・グラフ・カレンダー・チャット |
| 業務の流れ | 問い合わせ受付 → 確認メール → Excel 出力 |
| 仕組み | 認可・暗号・キャッシュ・レート制限・監査 |
| 基盤ポータル | パッケージ一覧・構成・ADR・依存グラフ |

## `apps/` にある理由

以前は `demos/` に置いていましたが、**2026-08 に `apps/` へ移しました**。

デプロイ単位・担当者・利用者のどれも他のアプリと同じで、
「デモだから」という理由で別扱いにする根拠がありませんでした。
health / ready・認可・監査も他のアプリと同じ基準で見ています。

## 決めていること

- **基盤のソースは編集しない。** 公開 API だけを使う。
  ここで内部に手を入れると「使い方の例」にならない
- **データはメモリ。** 保存の仕組みを持たないので、再起動で消える。
  見せたいのは基盤の使い方であって、保存の作り方ではない
- **画面を足したら `src/lib/nav.ts` に登録する。**
  トップとサイドバーはここから生成される
