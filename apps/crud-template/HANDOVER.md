# crud-template の引き継ぎ

**これは「新しいアプリの出発点」です。**

`pnpm new-app` でここから複製されます——
**ここを直すと、これから作られる全てのアプリに影響します**。

**この資料は基盤の一部**として扱います
（`docs/ops/HANDOVER.md` にも書いてよいものです）——
**他のアプリを作る人が真似する**ためです。

---

## 触るときの注意

| | |
|---|---|
| **動くことを必ず確かめる** | ここが壊れていると、**新しいアプリが全部壊れます**——**気づくのは作った人**で、原因はここだと分かりません |
| **例を消さない** | 「使っていないから」と消すと、**真似する見本が無くなります**——**削るより、コメントで「消してよい」と書く**方が親切です |
| **凝ったことを書かない** | ここは**出発点**です。**高度な書き方を置くと、それが標準だと思われます** |
| **`HANDOVER.md` を含める** | 複製先で**引き継ぎ資料が無い**状態にならないためです（検査で見張っています） |

---

## 気づいたこと

**新しいものを上に足してください。**

| 場所 | なぜ危ないか |
|---|---|
| **`HANDOVER.md` を複製に含めた（2026-08）** | 無いと、**気づいたことを基盤の HANDOVER（800 行）に書く**ことになり、**埋もれて誰も探せません**。`new-app` が**「どちらに書くか」の表つき**で作ります——**開いた人がその場で判断できる**ようにするためです |
