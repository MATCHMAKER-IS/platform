# @platform/bytes

バイト列の変換（base64・16 進・文字）。**日本語で落ちません**。

## これは何のためか

**`btoa` は日本語で例外を投げます。**

「経費精算」を base64 にしようとすると、**その場で落ちます**——
ブラウザの `btoa` は**ラテン文字しか受け付けない**ためです。

## 使う前に知っておくこと

| | |
|---|---|
| **URL に入れるなら URL 安全な形で** | 普通の base64 は **`+` `/` `=` が入り、URL で壊れます** |
| **壊れた入力は `undefined`** | 例外にはなりません——**呼び出し側で確かめて**ください |
| **base64 は暗号ではありません** | **誰でも戻せます**——秘密を隠す用途には使えません |
| **大きなデータは扱わない** | 数 MB を base64 にすると**1.33 倍**に膨らみます |

## よく使うもの

```ts
import { encodeBase64, decodeBase64, bytesToHex } from "@platform/bytes";
```
