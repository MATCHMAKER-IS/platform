# @platform/phone

電話番号の正規化と検証（日本と国際）。**同じ番号を別物として保存しない**ためのものです。

## これは何のためか

**同じ番号が別のものとして保存される**のを防ぐためのものです。

「03-1234-5678」「0312345678」「+81 3 1234 5678」——
**全部同じ番号**ですが、**文字列としては別物**です。

## 使う前に知っておくこと

| | |
|---|---|
| **不正なら `null`** | 推測しません——**「たぶんこの番号」で SMS を送ると、他人に届きます** |
| **国番号は `+` と 7〜15 桁** | それ以外は弾きます |
| **US と CA は同じ国番号（+1）** | **国は判別できません**——番号だけで国を決めないでください |
| **携帯と固定は形で見分けます** | ただし**確実ではありません**——番号の割り当ては変わります |
| **表示用と保存用を分ける** | 保存は `+81...`（国際形式）、表示は `03-1234-5678`——**保存を表示形式にすると、突き合わせできません** |

## よく使うもの

```ts
import { isValidE164, parseE164, detectCountry } from "@platform/phone";
import { normalizePhone, phoneType, isValidJpPhone, toE164, formatJpPhone } from "@platform/phone";

normalizePhone("０９０－１２３４－５６７８"); // "09012345678"(全角/ハイフン吸収)
phoneType("0312345678");                       // "landline"(固定/携帯/フリーダイヤル等)
toE164("09012345678");                          // "+819012345678"(SMS 送信用)
formatJpPhone("0312345678");                    // "03-1234-5678"
```

フォーム入力の正規化・バリデーション、SMS 送信前の E.164 変換に。国際番号にも対応。
