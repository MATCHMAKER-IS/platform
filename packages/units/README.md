# @platform/units

単位の表示（面積・重さ・長さ）。**日本の慣用単位**にも対応します。

## これは何のためか

**日本の不動産や建築では、坪・畳がまだ使われます。**

「50 平方メートル」より「**15 坪**」の方が伝わる相手がいます。

## 使う前に知っておくこと

| | |
|---|---|
| **畳の大きさは地域で違います** | 京間・中京間・江戸間——**実際の畳とは違う**ことを前提にしてください。ここでは**不動産公正取引協議会の基準（1.62 平方メートル）**を使っています |
| **単位の換算はしません** | 表示のためのものです——**計算は SI 単位（平方メートル）で**行ってください |
| **丸めで面積が変わって見えます** | 「15 坪」と「15.2 坪」では**印象が違います**——**契約書には SI 単位**を使ってください |

## よく使うもの

```ts
import { convertTemperature, round, convertLength } from "@platform/units";
import { convertLength, convertArea, convertTemperature } from "@platform/units";

convertLength(1, "km", "m");        // 1000
convertArea(10, "tsubo", "m2");     // 坪 → 平米(不動産・図面)
convertArea(6, "jo", "m2");         // 畳 → 平米
convertTemperature(100, "C", "F");  // 212
```

不動産(坪/畳)・物流(重量/体積)・製造(長さ)など、社内業務で頻出の単位換算に。
