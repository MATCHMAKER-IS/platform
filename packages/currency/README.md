# @platform/currency

通貨と丸め。**円だけでなく、外貨も扱います**。

## これは何のためか

**通貨によって小数の桁が違います。**

円は 0 桁、ドルは 2 桁、**ディナールは 3 桁**——
**一律に 2 桁で丸めると、合わなくなります**。

## 使う前に知っておくこと

| | |
|---|---|
| **知らない通貨は 2 桁として扱います** | 落とすより**動く**方を選んでいます——ただし**正しいとは限りません** |
| **丸め方は用途で選ぶ** | 会計は**銀行丸め（偶数丸め）**が慣行です。四捨五入だと**繰り返すうちに切り上げ側へ偏ります** |
| **金額を `number` で持つ危険** | 0.1 + 0.2 は 0.30000000000000004 です。**円は整数で持って**ください |
| **換算はしません** | レートは日々変わり、**いつのレートか**が業務で決まります——**外から渡して**ください |

## よく使うもの

```ts
import { currencyMeta, roundMoney, money } from "@platform/currency";
import { money, formatMoney, convert, sumMoney } from "@platform/currency";

const price = money(1980, "JPY");
formatMoney(price);                    // "￥1,980"
convert(money(100, "USD"), "JPY", 150); // 100USD → 15,000JPY
sumMoney([money(100, "JPY"), money(200, "JPY")]); // 合算(通貨不一致は弾く)
```

税計算・請求・複数通貨の集計に。丸めは通貨ごとの小数桁(JPY=0, USD=2)に従います。
