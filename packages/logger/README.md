# @platform/logger

ログの出力（構造化・伏せ字・レベル）。**後から探せる形で残す**ためのものです。

## これは何のためか

**後から探せる形で残す**ためのものです。

`console.log` は**伏せ字を通りません**——
**個人情報がそのままログに残ります**。

## 使う前に知っておくこと

| | |
|---|---|
| **業務データは入れ子でも隠します** | `{ user: { email: "..." } }` の中まで見ます——**浅い伏せ字では漏れます** |
| **`console.log` を使わない** | 検査で見張っていますが、**書けてしまいます**——**書かない習慣**が要ります |
| **レベルを使い分ける** | `error` は**人が動くもの**だけ。**何でも `error` にすると、本当のエラーが埋もれます** |
| **メッセージは検索できる形で** | 「失敗しました」では探せません——**何の・どれが・なぜ**を入れてください |
| **重複を作らない** | 同じことを 2 か所で記録すると、**件数が 2 倍に見えます** |

## よく使うもの

```ts
import { createLogger } from "@platform/logger";
import { createLogger } from "@platform/logger";
const log = createLogger({ base: { service: "internal-app" } });
log.info({ userId: 1 }, "ログイン成功");
```
